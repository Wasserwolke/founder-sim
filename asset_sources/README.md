# Asset Source Sheets

Hier werden die unbearbeiteten Produktions-Sheets abgelegt. Diese Dateien sind Quellen, nicht die Runtime-Assets des Spiels.

Namensschema:
`sheet_<category>_<batch>_2048.png`

Beispiele:
- `sheet_desk_objects_001_2048.png`
- `sheet_equipment_001_2048.png`
- `sheet_furniture_001_2048.png`

Kategorien:
- environment
- furniture
- equipment
- consumables
- desk_objects
- vehicles
- map
- ui

Die fertigen, vom Spiel verwendeten Dateien liegen unter `app/web/assets/`.
