# Founder Sim Asset Style Lock

- modern detailed pixel art
- crisp pixel clusters and stepped edges
- grounded realistic proportions
- cozy, moody, practical startup atmosphere
- warm indoor light + cool blue night/rain light
- clear readable silhouettes
- consistent pixel density, perspective, materials and scale
- no photorealism
- no 3D-render look
- no painterly style
- no anime/chibi
- no primitive 8-bit look

Physical asset trio:
- WORLD = in-game
- SPOT = shop/detail
- ICON = UI/inventory

Canonical references should stay visually consistent across all generated batches.
